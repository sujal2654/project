What is DDoS?

Distributed Denial of Service (DDoS) attacks aim to overwhelm a target system with massive amounts of traffic, making it unavailable to legitimate users.

Common Attack Types:

  • SYN Flood: Overwhelms with incomplete connection requests
  • UDP Flood: Floods random ports with UDP packets
  • HTTP GET Flood: Overwhelms web servers with requests
  • Ping of Death: Sends oversized ICMP packets
  • Slowloris: Keeps connections open as long as possible

Mitigation Techniques:

  • Content Delivery Networks (CDNs)
  • Rate limiting and filtering
  • Load balancing
  • Web Application Firewalls (WAF)
  • Anycast network diffusion
